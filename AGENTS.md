# Original Idea

Use https://docs.typesafe.ai/introduction as a "linter" to enforce semantic codebase lint rules. Define rules in plain English in markdown documents.

## Rules

- Do not add, change, or remove ANYTHING unless explicitly asked
- This means no tack-on chores, no nice-to-have code cleanup, no quick fixes while you're nearby
- It also means no tests unless explicitly asked. Especially for new features
